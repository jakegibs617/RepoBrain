01 Quick start

Give your agents a
memory.

Turn any codebase into a durable, searchable knowledge graph—locally, privately, and in about two minutes.

~2 minutes No account or API key Python 3.11+
01

Prerequisites

Make sure you’re ready

RepoBrain needs Python 3.11 or newer and uv, a fast Python package manager.

Terminal
$ python3 --version
uv --version
i

Don’t have uv yet? Install uv, then return here. Python can be downloaded from python.org.

02

Install

Create a clean environment

From the project folder, create a virtual environment and install RepoBrain with its development tools.

Terminal · project root
$ uv venv .venv
uv pip install -p .venv/bin/python -e ".[dev]"
03

Initialize

Prepare your project

Create RepoBrain’s local configuration in the repository you want to understand. The dot means “this folder.”

Terminal
$ .venv/bin/repobrain init .
✓

Ready. RepoBrain created .repobrain/config.json in your project.

04

Index

Build your knowledge graph

Scan the project and connect its files, symbols, imports, calls, tests, docs, and environment variables.

Terminal
$ .venv/bin/repobrain index .

Your graph stays in .repobrain/repobrain.sqlite. Nothing leaves your machine.

05

Explore

Ask your first question

Search the indexed project, look up a symbol, or ask RepoBrain to explain a file.

Try one—or all three
$ .venv/bin/repobrain search "database"
.venv/bin/repobrain find-symbol create_user
.venv/bin/repobrain explain file repobrain/cli.py
✦

You’re all set

Your repo has a memory now.
